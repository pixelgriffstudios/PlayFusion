# PlayFusion 1.0.2 roadmap

The following items are planned for the next maintenance image. This list can
change as real-hardware testing discovers additional release blockers.

- Fix MP3 and Digital Jukebox exit code 4 by removing the unsafe MPV gamepad
  action mapping while preserving intentional Back/Exit controls.
- Make removable-media artwork scanning finish the complete queue on the first
  insertion, show progress, and reuse cached covers on later insertions.
- Add the active profile thumbnail and profile name to the top-right corner of
  the home screen.
- Make audio output selection reliable across reboot and profile changes.
- Add visible scrolling to Storage Manager for systems with many internal
  expansion drives.
- Re-run the complete real-hardware release checklist and document every fix in
  `CHANGELOG.md`.
